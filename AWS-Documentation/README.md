
# AWS Hands-on Lab Documentation

A collection of hands-on exercises documenting my practical learning and exploration of **Amazon Web Services (AWS)**.

This repository contains step-by-step notes covering AWS service configuration, cloud infrastructure, monitoring, automation and application deployment.

## Topics Covered

- **Compute:** [Amazon EC2](AWS-Lab-02-"EC2-Instance-Configuration".md), Auto Scaling, Elastic Beanstalk
- **Networking:** Amazon VPC, Elastic IP, Elastic Load Balancing
- **Storage:** Amazon S3, EBS, EFS
- **Databases:** Amazon RDS, DynamoDB
- **Security:** AWS IAM
- **Monitoring:** Amazon CloudWatch, Amazon SNS
- **Content Delivery:** Amazon CloudFront
- **Infrastructure as Code:** AWS CloudFormation
- **Serverless & Event-driven Services:** AWS Lambda, Amazon EventBridge

## Tools & Technologies

- Amazon Web Services (AWS)
- Linux / Ubuntu
- AWS CLI
- Python
- YAML
- Git & GitHub
- Markdown

## Documentation

Each Markdown file contains the corresponding lab procedure, configurations, commands and observations.

These exercises are intended as practical learning references and are not production deployment guides.

## Purpose

To document my hands-on experience with AWS services and build a practical understanding of cloud infrastructure, administration and automation.
